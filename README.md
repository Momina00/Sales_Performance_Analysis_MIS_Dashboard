# Sales Performance Analysis & MIS Dashboard

## Project Overview

This project focuses on analyzing sales data using Microsoft Excel and presenting the findings through a simple MIS dashboard.

The goal was to turn raw sales data into useful business insights such as sales performance, profit, order volume, regional performance, and monthly sales trends.

## Dataset

The dataset contains **9,994 sales records** with information related to:

- Orders and customers
- Order and shipping dates
- Regions and categories
- Products and sub-categories
- Sales
- Quantity
- Discount
- Profit

## What I Worked On

- Cleaned and prepared the raw sales data.
- Converted date fields into usable Excel date values.
- Checked important columns for missing values.
- Created a helper field to calculate the number of unique orders.
- Used Excel formulas to calculate key business metrics.
- Created PivotTables for different areas of analysis.
- Built a dashboard to present the results in an easy-to-understand format.

## Analysis Performed

The project includes analysis of:

- Total Sales
- Total Profit
- Total Orders
- Total Quantity Sold
- Monthly Sales Trend
- Sales by Region
- Sales by Category
- Profit by Region
- Sales by Sub-Category

## Dashboard

The final dashboard contains KPI summaries and charts that provide a quick view of overall sales performance.

### Key Metrics

- **Total Sales:** ₹2,297,201
- **Total Orders:** 5,009
- **Total Quantity Sold:** 37,873
